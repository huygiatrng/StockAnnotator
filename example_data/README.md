# Example Data

This folder contains example data files that can be used to test the application.

## Files

- `sample_stock_data.csv` - A small sample of stock price data that can be used to demonstrate the application's features
- `SP500.csv` - If available, a sample of S&P 500 index data

## Usage

You can use these files to test the application by:

1. Starting the application: `streamlit run main.py`
2. Clicking "Browse files" in the sidebar
3. Navigating to the `example_data` folder
4. Selecting one of the sample CSV files

This provides a quick way to see how the application works without needing to find your own data files.
